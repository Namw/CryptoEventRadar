# Crypto Market Intel Agent

这份目录用于沉淀你的求职主项目规划，避免继续把想法分散在多个 demo 里。

建议执行顺序：

1. 先看 `00_overall_plan.md`，确认主线和边界。
2. 再看 `01_project_blueprint.md`，按结构开始搭项目。
3. 然后看 `02_data_model.md`，把表和数据流定死。
4. 最后按 `03_week1_checklist.md` 逐项打勾。

使用原则：

- 只做一个主项目：`crypto-market-intel-agent`
- 所有新想法先丢进 `backlog.md`
- 当前阶段不做自动交易
- 每周至少形成一个可演示结果
