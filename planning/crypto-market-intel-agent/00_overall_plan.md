# 总计划

## 项目一句话定义

做一个面向加密市场的事件研究 agent，自动收集交易所公告和市场事件，完成事件抽取、分类、去重、资产映射、风险优先级排序，并输出日报和告警。

## 项目边界

- 当前主线：交易所公告 + 市场事件研究
- 第一版用户：你自己，假设身份是交易员或研究员
- 第一版目标：本地可运行、可复盘、可评估
- 当前不做：自动交易、复杂前端、大规模回测、多账户风控

## 执行原则

- 只有一个主项目
- 先做闭环，再做高级能力
- 每周必须有可运行结果
- 每个新想法先记到 backlog，不插队开发
- 优先做能写进简历的功能，不做装饰性功能
